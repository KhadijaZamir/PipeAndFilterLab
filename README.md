# PipeAndFilterLab
### **Description**  

This project implements the **Pipe and Filter** pattern in Java, where a list of numbers is processed through a sequence of filters. Each filter performs a specific transformation or filtering operation on the data before passing it to the next stage.  

The filters in this implementation include:  
- **Filtering even numbers** – Removes all odd numbers from the list.  
- **Squaring numbers** – Replaces each number with its square.  
- **Filtering numbers greater than 10** – Keeps only numbers greater than 10.  
- **Cubing numbers** – Replaces each number with its cube.  

This approach ensures modularity and reusability, making it easy to add or modify filters without affecting the overall pipeline structure. The project demonstrates functional programming concepts using Java Streams and Lambda expressions.
